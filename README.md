# LASGen

Ming Chen, Yujie Xing, Jiongyi Chen (✉️), and  [Wenrui Diao](https://diaowenrui.github.io/) (✉️). LASGen: Synergistic Harness–Seed Co-Synthesis for High-Coverage Library Fuzzing. The 21st ACM ASIA Conference on Computer and Communications Security (ASIACCS'26), Bangalore, India. June 1-5, 2026.
